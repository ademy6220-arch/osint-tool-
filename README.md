# ❄️ LUXA OSINT PRO TOOL

LUXA is a lightweight Open Source Intelligence (OSINT) tool designed for **educational and security research purposes only**.

It collects only publicly available information such as:
- Domain DNS records
- IP geolocation (public API)
- Basic network information

⚠️ This tool does NOT perform tracking, hacking, or access private data.

---

## 🚀 Features

- 🌐 Domain DNS lookup
- 📍 IP information (public API)
- 🧾 Simple structured JSON report
- 💾 Local report export
- 💻 Terminal-based interface
